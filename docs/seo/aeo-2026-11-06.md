## Validation reproductible

`npm run build` puis `python scripts/check-search-pages.py`.
Le contrôle examine chaque URL du sitemap : H1, canonique, absence de noindex/nosnippet, données structurées valides, FAQ présentes dans le HTML, liens internes, liens vers le guide et la gravure, catalogue exclu. Vérifie que la page gravure ne pointe pas vers le panier.

`robots.txt` autorise déjà tous les robots via `User-Agent: * / Allow: /`. Aucun changement nécessaire. Les tests HTTP avec un User-Agent de robot ne prouvent pas qu’une requête issue des véritables IP du moteur passera, ni qu’un crawl a eu lieu.

## Suivi

Comparer les mêmes questions, moteurs, langues et zones dans la durée : clear ice, clearice, gravure clear ice, glaçons transparents, fournisseur clear ice, glaçons personnalisés logo, plus les variantes des cinq villes. Consigner la date, la question exacte, le moteur, le domaine/page citée et les concurrents. Les moteurs inaccessibles restent « non mesurés ». Les résultats d’un moteur de recherche ne valent pas citation dans une réponse IA.
